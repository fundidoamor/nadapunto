# NADA PUNTO COM

Primera versión del sitio web de Nada Punto Com.

## Archivos
- `index.html` — estructura
- `style.css` — diseño
- `script.js` — interacción
- `assets/` — imágenes y videos

## Subir a GitHub
1. En tu repo `nadapunto`, pulsa **Add file > Upload files**.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `assets`.
3. Haz commit.

## Publicar gratis en Vercel
1. Crea cuenta en Vercel usando GitHub.
2. **Add New > Project**.
3. Importa `nadapunto`.
4. Framework Preset: **Other**.
5. Deja Build Command y Output Directory vacíos.
6. Pulsa **Deploy**.

Vercel te dará una URL gratuita tipo `nadapunto.vercel.app`.

## Cambios rápidos
- Cambia los enlaces de Instagram en `index.html`.
- Cambia el correo temporal.
- Sustituye los bloques `IMAGEN / VIDEO` por contenido real dentro de `assets/`.
